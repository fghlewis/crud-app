# Notes App

A simple app for creating, editing, and deleting notes.

## How to use it

1. Run the development server:
   ```bash
   npm run dev
   ```

2. Open your browser and go to:
   ```
   http://localhost:3000/notes
   ```

3. From there you can:
   - **Create a note** — fill in the title and body fields, then click Submit
   - **Edit a note** — click the Edit button on any note, make your changes, then click Save
   - **Delete a note** — click the Delete button on any note to remove it
